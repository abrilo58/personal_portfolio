# Abrham Wondimu - Personal Portfolio

One-page portfolio built with HTML, CSS and Bootstrap 5.3, with a little vanilla JavaScript.

Features dark/light themes, a typing effect, scroll-reveal animations, a filterable project grid and a contact form that opens your email app.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
uv run --no-project python -m http.server 5500
```
